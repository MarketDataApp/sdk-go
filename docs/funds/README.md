# Funds (Go SDK)

Access historical net asset value (NAV) candles for mutual funds. The Go SDK exposes these endpoints through the `client.Funds` service.

## Mutual Funds Endpoints

- [Fund Candles (Go SDK)](./candles.md) — Fetch historical daily NAV candles for a mutual fund with the Go SDK Candles and GetCandles methods on the Funds service, with times in US Eastern.
