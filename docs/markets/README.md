# Markets (Go SDK)

Check whether a market was open, closed, or closed early on any trading day. The Go SDK exposes these endpoints through the `client.Markets` service.

## Markets Endpoints

- [Market Status (Go SDK)](./status.md)
- [Status History](./status-history.md) — Call StatusHistory on the Go SDK Markets service to get the open or closed market status for every day in a date range, one entry per day.
